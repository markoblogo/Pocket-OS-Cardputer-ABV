# Physical-device demo plan

Target: 60-90 seconds, after rc3 has been flashed and its advertised paths checked.
Use a camera filming the actual Cardputer; software captures must be labelled.
No GPS, invented tracking route, model response or unverified Voice export.

| Time | Shot | What must be real |
| --- | --- | --- |
| 0-10s | Device, version and Launcher | rc3 About screen, actual keyboard |
| 10-25s | Music list, play and shuffle | A licensed/original short audio sample |
| 25-40s | Reader, page change, bookmark | Public-domain or owner-written sample |
| 40-55s | Turn device, play Tetris, leave | Portrait mapping and landscape restoration |
| 55-70s | Klondike sequence and Doom target | Actual successful moves and hits |
| 70-90s | Companion, SD workflow, release URL | Actual UI/status; no private paths or passwords |

Before filming, run the Games checklist, confirm media still opens after leaving
Games, disable notifications on the filming Mac and use a synthetic SD library.
Voice is optional footage only after its own verified offload test. GPS is paused.
The demo may describe the firmware as a release candidate; it must not imply
stable certification or that every experimental feature works.

Suggested closing caption: "Pocket OS for Cardputer ADV / source and pre-release
on GitHub". Publish footage only after the owner reviews the actual cut.
